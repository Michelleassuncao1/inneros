# Kit de démarrage InnerOS — Phase 1

Institut Mindset en Action® — version du 5 octobre 2026.

Ce dossier contient tout ce qu'il faut pour construire InnerOS avec Claude Code, étape par étape, sans savoir coder.

## Contenu

| Fichier | À quoi il sert |
| --- | --- |
| `CLAUDE.md` | Les règles que Claude Code lit à chaque session (anonymat, seuil, IA, charte, méthode de travail) |
| `docs/CAHIER_DES_CHARGES_V1.1.md` | Le besoin complet, version 1.1 |
| `docs/PROMPTS_CLAUDE_CODE.md` | **Le guide à suivre** : un prompt à copier par étape, et quoi vérifier |
| `docs/CHARTE_GRAPHIQUE.md` | L'identité visuelle IMA déclinée pour InnerOS |
| `design/tokens.css` | Les couleurs, polices et réglages de la charte, prêts pour le code |
| `prompts/redaction-rapport.system.md` | Le prompt système de l'IA qui rédige les brouillons de rapport |
| `instruments/` | L'emplacement des questionnaires officiels (à fournir par IMA) |
| `assets/logo-ima-provisoire.png` | Logo provisoire, à remplacer par le fichier officiel |
| `.env.example` | La liste des clés à renseigner, sans aucune valeur |

## Pour commencer

1. Lisez la partie « Avant de commencer » de `docs/PROMPTS_CLAUDE_CODE.md`.
2. Ouvrez ce dossier dans Claude Code.
3. Copiez le prompt de l'étape 1 et laissez Claude Code vous proposer son plan.

Règle d'or : une étape à la fois, et rien n'est exécuté sans votre accord.
