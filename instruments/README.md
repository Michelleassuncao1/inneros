# Instruments (questionnaires)

Placez ici les fichiers officiels reçus des détenteurs des questionnaires :

- COPSOQ III — version nationale validée (une par langue), sans les items d'engagement au travail (WE) ;
- CBI — version validée en français et en portugais (Brésil), après confirmation écrite du NFA ;
- Flourishing Scale — traductions validées en français et en portugais (Brésil).

Claude Code les convertit dans le format JSON du projet **sans modifier un seul mot** (voir l'étape 5 du guide des prompts). `exemple-format.json` montre la structure attendue, avec des items fictifs.
